# 🍧 My Portfolio Website
A portfolio website built with JavaScript and React.js to showcase my projects, skills, and information.

View it live here: https://wania-sharif.github.io/wania-portfolio/

## ✨ Features
Responsive Design: Fully optimized for mobile, tablet, and desktop viewports.

Project Showcase: An interactive list displaying featured projects with direct links to GitHub repositories. Utilizes Framer Motion for a smooth horizontal navigation during vertical scroll

### Page sections: 
- Introduction
- Projects
- About
- Contact

## 🛠 Tech Stack
**Frontend:** JavaScript with a React.js framework

**Styling:** CSS

**Deployment:** GitHub Pages
